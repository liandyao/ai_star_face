# 明星人脸数据库 - 爬取说明

## 数据来源

数据来自 [中国明星网](http://www.cecet.cn/stardata/)，共爬取了 4 个分类的明星信息。

|------|---------|----------|----------|--------|
| 内地明星 | http://www.cecet.cn/stardata/0001/ | `data/all_star_20260426.json` | 2336 | 2336 |
| 港台明星 | http://www.cecet.cn/stardata/0002/ | `data/gangtai_star_20260426.json` | 871 | 871 |

> 所有明星均成功抓取到图片URL，图片覆盖率 100%。

## 数据格式

每条记录包含以下字段：

```json
{
    "name": "李敏镐",
    "person_id": "li_min_gao",
    "gender": 1,
    "url": "http://www.cecet.cn/upimg/allimg/140507/0841380.jpg",
    "remark": ""
}
```

| 字段 | 说明 |
|------|------|
| `name` | 明星姓名 |
| `person_id` | 姓名拼音标识（通过 pypinyin 生成） |
| `gender` | 性别：1=男，2=女（基于姓名用字的启发式判断，非100%准确） |
| `url` | 照片URL（来自详情页 #fontzoom 下的第一张图片） |
| `remark` | 备注（暂为空） |

## 爬取方法

- **爬取脚本**：`scrape_stars.py`（内地）、`scrape_category.py`（港台/日韩/欧美通用）
- **爬取流程**：
  1. 遍历列表页，收集所有明星详情页链接和姓名
  2. 逐个访问详情页，提取 `#fontzoom` 下第一个 `<img>` 的 `src` 作为照片URL
  3. 去重后保存为JSON文件
- **进度保存**：每50条自动保存进度到中间文件，支持断点续爬
- **编码处理**：网站使用 GBK/GB18030 编码，脚本自动检测

## 注意事项

- `gender` 字段为启发式判断，基于姓名中的常见男女用字，**可能存在误判**
- `person_id` 由中文姓名通过 pypinyin 自动生成，日韩/欧美人名的拼音可能不够准确
- 图片URL来自 `cecet.cn` 服务器，长期可用性无法保证，建议及时下载保存
